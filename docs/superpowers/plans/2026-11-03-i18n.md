# 多語言 (i18n) 架構 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 讓 App 支援繁體中文、簡體中文、英文，所有使用者可見文字（介面、曲目內容、通知、小工具、原生 App 名稱）都走翻譯層，並可在 App 內切換語言。

**Architecture:** 介面文字用 Flutter gen-l10n（ARB，範本 `app_zh.arb` 為繁中），曲名／演出者／迴向文放 `lib/core/content/` 內容目錄，由 `ChantConstants.applyLocale` 依語言重建曲目清單。語言解析為純函式 `resolveAppLocale`，ViewModel 持有已解析 `Locale` 並推送給無 `BuildContext` 的服務。

**Tech Stack:** Flutter 3.47.6、`flutter_localizations`、`intl`、provider、shared_preferences、home_widget、audio_service。

**Spec:** `docs/superpowers/specs/2026-11-03-i18n-design.md`

## Global Constraints

- 語言：`zh_Hant`（主語言＝現有文字）、`zh_Hans`、`en`；英文 App 名稱 `Buddha Counter`，簡中 `念佛计数器`，繁中 `念佛計數器`。
- `l10n.yaml`：`arb-dir: lib/l10n`、`template-arb-file: app_zh.arb`、`output-dir: lib/l10n/generated`、`nullable-getter: false`、`output-class: AppLocalizations`；產生檔 commit 進 repo。
- `app_zh_Hant.arb` 只含 `"@@locale": "zh_Hant"`；`app_zh.arb`、`app_zh_Hans.arb`、`app_en.arb` key 完全一致。
- 每個 ARB key 有 `@key.description`；含數字的句子用型別化 placeholder，英文單複數用 ICU `plural`，禁止字串拼接組句。
- Key 命名：`<畫面或功能><用途>` lowerCamel（例：`autoStopSheetTitle`）；共用字用 `common` 前綴（`commonCancel`、`commonSet`、`commonConfirm`、`commonClose`）。
- 語言偏好存 `pref_locale`，值 `system` / `zh_Hant` / `zh_Hans` / `en`，預設 `system`。
- 解析：zh + `Hant` 或地區 `TW`/`HK`/`MO` → `zh_Hant`；zh + `Hans` 或地區 `CN`/`SG`/`MY` 或純 `zh` → `zh_Hans`；`en*` → `en`；依手機語言清單順序取第一個符合者；全不符合 → `en`。
- 繁中曲名順序維持「音檔 metadata → 程式碼常數」；簡中／英文為「該語言目錄 → metadata → 繁中」。
- 每週起始維持週一；數字維持 ASCII；不做 RTL。
- 日期顯示用 ARB 整數 placeholder（`year`/`month`/`day`）＋英文另帶 `monthName`（以 `DateFormat.MMMM('en')` / `DateFormat.MMM('en')` 產生），不依賴 `initializeDateFormatting`。
- 繁中使用者看到的所有文字與現在**逐字相同**（現有 widget test 斷言不改字）。
- 英文較長時用較短譯法，不縮字級、不用 `FittedBox` 硬塞；窄螢幕基準 320dp 寬。
- 專案檔案維持 LF 換行；不得使用會把 LF 轉成 CRLF 的寫檔方式。

## Review Focus

- 手機語言為 `zh-HK`（無 script code，最常見的香港設定）→ 必須是繁中，不能落到簡中。（Task 1 測試）
- 馬來西亞使用者手機設英文、App 內手動選簡中 → 重開 App 後仍是簡中。（Task 1 測試）
- 已選某分類標籤篩選中切換語言 → 篩選仍生效、結果數量不變，不會變成「全部」或空清單。（Task 7 測試）
- 自動計數播放中切換語言 → 計數與播放不中斷，鎖定畫面曲名換成新語言。（Task 10 測試）
- 英文 + 320dp 寬 + 自動停止設為「Goal 10000」→ 自動計數小按鈕列、底部分頁列不溢位。（Task 12 測試）
